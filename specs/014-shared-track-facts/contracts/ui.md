# Contract: screens touched

**Settings, Audio data card** (BPM and key)
- A one-sentence notice (FR-011), always shown when the server is set up and the user is signed in: "BPM and key found by a lookup are shared with the other people on this server; your library, plays, rekordbox values and mixes never are."
- After a run that used the store: "From the shared store: N tracks, no lookup needed. Shared: M new." When `shared.error` is set: "The shared store could not be used (<reason>); everything was looked up outside as before."
- The progress label while the store is asked: "shared store".
- Without server settings, signed out or in the demo: none of these lines, no notice.

**Settings, Artist reach card**
- The same notice with "listeners and fans" for the second step, and the same two result lines ("N artists' numbers from the shared store").

**Nowhere else**: no banner, no Mix, Crate or Under the radar change; no screen to list or edit the store.
